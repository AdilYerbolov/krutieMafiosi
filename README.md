# Последний стол — Godot 4.3+ (GDScript)

Откройте папку проекта в Godot 4.3 или новее (рендерер Compatibility) и нажмите F5.
При первом открытии редактор сам импортирует фон `assets/backgrounds/dining_room.jpg`.

## Структура игры
Пролог (дворецкий) → Ужин 1 → интерлюдия → … → Ужин 6 → концовка (A–E по счётчикам).

Каждый ужин:
1. **Рассадка** — клик по гостю внизу, затем по месту. Наведите на место: видно его значение и связи с соседями.
2. **Вино** — выберите, кому налить первым → мини-игра (удерживать ПРОБЕЛ/кнопку, отпустить в золотой зоне).
   Недолив/перелив/пролив = **штраф**: −доверие, +напряжение у гостя, реплика-упрёк на ужине.
3. **Особое блюдо** — выберите гостя и блюдо → мини-игра из 3 этапов (остановить бегунок в зелёной зоне).
   Счёт 0–6: ≥5 безупречно, 3–4 хорошо, 2 посредственно, ≤1 блюдо испорчено = **штраф**.
4. **Ножи** — оставить или убрать у каждого гостя.
5. **Где стоять** — у стола или у двери.
6. **Диалог ужина** в стиле новеллы поверх стола. На табличке: имя, прозвище, роль и связь
   с тем, к кому обращена реплика. Клавиши: клик/пробел — далее, Ctrl — быстро, H — скрыть UI
   (посмотреть на стол: там происходят «странности»), L — лог, J — досье.

Между ужинами — VN-сцены с прислугой и гостями: Бенито (дворецкий), Лючия (горничная),
Карло (повар), отец Анджело, инспектор Руджеро. Они раскрывают лор и дают выбор, двигающий руты.

## Спрайты (полный список — в SPRITES.md)
Кладите PNG в `assets/sprites/`:
- `sara.png` — основной спрайт; `sara_cold.png` — вариант настроения (используется, если в реплике `mood="cold"`).
- id: don, sara, luigi, marco, nora, frank, emil, rose, joe, stranger, benito, lucia, carlo, angelo, ruggero.
Пока файла нет, рисуется цветной силуэт с подписью нужного имени файла. Высота подбирается автоматически
(по умолчанию 600 px в обычных сценах, 470 px поверх стола). Для фишек за столом берётся верхняя часть спрайта.

## Фоны
Для интерлюдий используются кадры главной комнаты (hall, study, kitchen, backdoor, empty).
Положите `assets/backgrounds/<ключ>.png` — и он заменит кадр.

## Где править
- `autoload/chars.gd` — персонажи, роли в игре, связи между персонажами (REL).
- `autoload/story_dinners.gd`, `story_interludes.gd` — диалоги и выборы (данные; хелперы в `story_base.gd`).
  Шаги: `s()` реплика, `n()` рассказчик, `ch()/o()` выбор, `iff()` условие, `addv/setv` счётчики и флаги,
  `relc()` связь, `clue()` запись в досье, `fx()` эффект на столе, `intro()` карточки персонажей.
- `autoload/story.gd` — рассадка, эффекты вина/блюда/ножей, штрафы, реакции, выбор концовки (`pick_ending`).
- Эффекты стола (`fx`): peek, swap, silent_swap, blink, vanish, appear, extra_guest, ghost, remove_extra,
  item_flash, flicker, reflect, stare, laugh, empty_chair, player_leave, vanish_many, shake.

## Тест
`dev/test_run.gd` — бот, проходящий игру целиком:
`godot --headless --path . -s res://dev/test_run.gd -- <seed>`
На титульном экране есть кнопки «Тест, с ужина: 1–6».

## Ветвление интерлюдий
Интерлюдии (пролог + 5) ветвятся по лидирующему руту (`lead()`: order / sara / chaos / stranger)
и по судьбам: Антонио и его жена, Калло, Луи (жив / бежал / убит), Марко (союзник / убит), Роза, Джо,
Эмиль, Дон (отпет или нет), Незнакомец, штрафы за мини-игры. Условия считаются в начале интерлюдии (`has(...)`),
а изменяемые внутри неё — через `iff(...)`. Подсказки Бенито (`wine_tip`) и Карло (`dish_tip`)
расширяют зоны в мини-играх. Концовки получают эпилог по судьбам (`epilogue()`).
